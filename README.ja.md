# Time Study Desk / 動画作業分析

[English](README.md)

作業動画を見ながら同じ作業を工程・回ごとに区切り、境界を修正して分析データを保存します。登録・インストール・動画のアップロードは不要です。実行時の外部ライブラリは使用しません。

**v0.7.0 — 開発版です。** 反復計測・保存再開・件数付き統計・根拠映像の見直しに加えて、時間表／集計／区間明細のCSV出力に対応しました。正式版ではありません。

## スクリーンショット

アプリ試験で撮影した日本語・英語・スマートフォン幅の画像を、Actionsの`time-study-evidence-*`成果物内の`test-results/screenshots/`へ出力します。幾何図形の短い動画は人工の試験素材であり、実在する作業の計測結果ではありません。テンプレートから継承したリポジトリ画像は、この版の検証証跡として扱いません。

## できること

- 動画一本の選択・ドラッグ＆ドロップ、再生・一時停止・シーク、0.25〜2倍速、±0.1秒／±1秒の微調整、音量・ミュート。
- 初回は「ここから開始」→「ここで区切る」→「この回を終了」。仮の工程名で計測でき、事前に工程名が分かる場合は改行区切りで入力する副導線もあります。
- 次回以降は選んだ手順で明示的に開始します。最後の工程では主ボタンが終了に変わり、次の回を自動開始しません。回と回の間の時間は工程時間へ含めず、別に表示します。
- 時間順の回一覧から過去の回を選んで修正できます。見直し対象と計測中の回は別に管理します。
- 工程名の訂正は全回へ反映します。工程順・開始終了条件の変更は別手順として保存し、過去の回の条件は変えません。工程の分類変更や新規選択肢からの除外でも過去記録を削除しません。
- 中断・未観測を工程時間と分けて記録します。中断から戻ると同じ工程の続きを記録し、未観測の工程は分かった部分だけを保持します。
- 「この工程は実施なし」は、工程・未観測の確定区間がない場合だけ指定できます。0秒の工程を作りません。最後の工程を実施なしにしても、回を自動完了しません。
- 区間の分割・隣接区間の結合・割当て変更、この回だけの追加工程・やり直しに対応します。合計時間は保ち、異なる割当てやメモをまとめる場合は確認します。次回の手順は変えません。
- 工程の状態を見直して、最後の確定境界で明示的に完了できます。記録の割当てを外した工程は勝手に実施なしとせず、未確定に戻します。回の削除はUndo可能で、動画や工程定義は削除しません。
- 秒数の直接入力・現在の再生位置・スライダーによる共有境界の修正。前後の工程時間が連動し、不正な時刻や隣を越える境界は記録を変えずに拒否します。
- 工程名、分析・回・工程の実施・区間のメモの編集。最大100操作／差分合計16 MiBまでの取り消し・やり直し。
- 動画を含まない分析JSONの手動保存と再読込。読み込み前に保存形式、ID・参照、境界、文字数・件数、10 MiB上限まで検証し、成功後だけ現在の分析を置き換えます。
- 元動画は別操作で再接続します。サイズ・縦横・長さ（差100 ms以内）を照合しますが、一致しても同一動画とは断定せず確認を必須にします。記録済み境界より短い候補は拒否します。
- 分析データだけをIndexedDBへ自動保存できます。初期値はONで、成功した保存だけrevisionを進めます。別タブの新しいrevisionを検出した場合は上書きせず競合を表示します。前回データの復元・ブラウザ内データの明示削除にも対応します。
- 日英表示とライトUI。スマートフォンは「計測／見直す／結果」で切り替えます。「結果」は手順ごとの記録回数／対象回数／除外回数／未完了回数、全体統計、工程別平均とn、ゼロ始点の棒グラフ、工程×回の時間表を表示します。実施なし・未観測・未完了を0秒として扱いません。
- CSVは時間表・集計・区間明細を一つずつ保存できます。UTF-8 BOM、CRLF、全セル引用、欠損と0の区別、状態・除外理由の保持に対応し、表計算ソフトで数式として解釈され得る利用者文字列はCSV内だけテキスト化します。

## 使い方

最新ソースから生成した`dist/index.html`または`time-study-desk.html`を開き、動画を選択します。作業の開始位置で「ここから開始」、工程が変わる位置で「ここで区切る」、最後に「この回を終了」を押します。次は「計測」に戻り、次の作業の開始位置で「次の回をここから開始」を押します。「見直す」で回を選んで時刻を修正できます。「結果」には件数付き統計、工程×回の時間表、選択回の内訳・除外設定と、既存の回一覧・手順管理があります。手順編集は保存したときだけ反映され、キャンセルでは変更しません。「分析データを保存」で`.tsd.json`をダウンロードします。その下のCSV操作から、時間表／集計／区間明細を一回につき一ファイルずつ保存できます。

保存名は編集でき、拡張子は分離しています。「ダウンロードを開始しました」はブラウザへ渡したことを表し、保存先への書き込み確認ではありません。自動保存はIndexedDBが実際に利用できる環境で初期値ONです。動画は保存しません。保存領域が使えない／不足する場合も、警告を表示して手動JSON保存と計測は続けられます。

過去の回を見直していても、動画末尾に到達したときに未完了とするのは現在計測中の回です。自動で「完了」にはしません。取り消して境界を修正し、明示的に終了するか、未完了のまま保存できます。画面を離れた後は最後の確定境界から明示的に再開します。離席時間を動画内の中断として追加しません。

反復計測の未完了回は記録を残したまま次の回の準備へ進めます。他に計測中の回がある間は、過去の未完了回を同時に再開できません。開始位置や境界修正が別の回と重なる場合は拒否します。

### 中断・未観測の記録と見直し

計測画面の「その他の記録」から、中断・観測できない区間・実施なしを指定します。「工程へ戻る」で中断や未観測の区間を終了し、元の工程の続きに戻ります。動画の再生を一時停止する操作とは別です。

「見直す」の「区間の分割・結合・割当て」では、対象区間と残す割当てを選んで変更します。分割位置は対象区間の内側の動画時刻です。異なる割当て・メモを結合する場合は、選択した内容へまとめることを確認します。この回だけのやり直しは、区間を分割し、追加した工程の実施へ該当区間を割り当てます。

工程ごとの「実施の状態を見直す」では、観測済み・実施なし・未観測・未確定を指定できます。未観測区間を残したまま観測済みにするなど、記録と矛盾する変更は拒否します。計測中の割当て変更はその回を中断します。全工程の状態が確定し、正の長さの区間があると、「この回を完了にする」で余分な時間を追加せず明示的に終了できます。

### 結果と根拠映像

「結果」で集計する手順を選びます。全体時間は完了かつ集計対象の回だけを母集団にし、記録済み工程・中断・未観測の平均も同じ回集合から計算します。工程別平均は、その工程値を確定できる回だけを母集団にするため、工程ごとにnが異なる場合があります。**工程平均を足して全体平均にはしません。**

「実施なし」は0秒ではありません。一部未観測の工程は分かっている工程時間を保持しますが、その回の工程平均には入れません。未完了回は一覧に残しつつ標準の統計から外します。完了回を集計対象外にする場合は理由が必須で、行自体は残ります。

回の全体時間、工程時間、中断・未観測の数値を押すと「見直す」へ移り、保存された根拠区間の開始位置へシークして停止します。自動再生はしません。「この区間を再生」を明示的に押すと区間末尾付近で停止しますが、フレーム単位の停止精度は保証しません。動画未接続でも時間範囲は確認でき、動画を再接続するまで再生だけを無効にします。

### 再読込・元動画の再接続・自動保存

「保存した分析を開く」から`.tsd.json`を選びます。ファイルは端末内で検証し、現在の分析を置き換えるのは検証成功＋確認後だけです。読み込んだ分析は動画未接続の状態で開き、結果確認・名称編集・JSON保存はできますが、動画を使う計測・シークは無効です。

「元動画を選び直す」で動画候補を選びます。候補情報が一致しても同一動画の証明とは扱わず、本人確認後に接続します。ファイル名・更新日時の違いは警告、サイズ・縦横・100 msを超える長さ差、記録済み最後の境界より短い候補は拒否します。再接続後も自動再生しません。

自動保存は一つの分析を復旧するための補助で、複数プロジェクト管理ではありません。確定操作後750 ms、連続操作時は最長5秒で保存を試みます。別タブのrevisionが新しければ自動上書きを止めます。「ブラウザ内の分析データを削除」はこのアプリの分析用保存領域だけを消し、元動画やダウンロード済みファイルは削除しません。

## プライバシーと制約

動画と分析はブラウザ内で処理します。動画はFile参照とBlob URLとして扱い、全バイトをJavaScript配列へ複製しません。映像・ファイル名・工程名・メモをサーバーへ送信しません。分析の自動保存はブラウザ内のIndexedDBだけを使い、動画は保存しません。言語と自動保存ON/OFFは端末側設定です。分析JSONにはメタデータ・時刻・メモを含めますが、動画・端末の絶対パス・Blob URL・Undo履歴は含めません。ブラウザ保存領域を永久保管・暗号化保管とは説明しません。

通常版は`connect-src 'none'`、`media-src blob:`を使用し、Worker、外部フォント、解析タグ、CDNを追加していません。自己展開ローダーと展開後のアプリは別に確認します。[SECURITY.md](SECURITY.md)も参照してください。

入力上限は動画一本・0バイトより大きく8 GiB以下・正の有限長で24時間以下です。映像とシーク可能な位置を取得できる動画に限ります。これはアプリの入力方針であり、**全端末で8 GiBを再生できるという保証ではありません**。コーデック対応はブラウザの実際の読み込み結果で判断します。動画の変換は行いません。通常速度の撮影を前提とし、スロー撮影・タイムラプス・編集で伸縮された時間から実時間を復元しません。

時刻は動画の`currentTime`から取得し、整数マイクロ秒で保持します。これは演算上の単位であり、**マイクロ秒精度やフレーム精度の保証ではありません**。再生速度を工程時間に掛けたり割ったりしません。数値は選択した動画の観測時間で、標準時間や作業者の評価ではありません。

## 動作確認の範囲

WindowsのActionsでは、通常の単一HTML経路を生成した通常版・自己展開版の`file://`直接起動で確認します。IndexedDB永続化の試験だけは、同じ生成HTMLをloopback専用の開発サーバーから開いて安定したoriginを用意します。実行時にサーバーは不要です。`file://`の保存可否は環境ごとに検出し、一律対応とは説明しません。

Android／iPhoneの実機、macOS Safari、Edge、Firefox、公開HTTPS環境、大容量の実動画は未確認です。スマートフォン幅のエミュレーションを、OSのファイル選択・保存の実機確認として扱いません。自己展開版には`DecompressionStream`が必要です。

## 開発・ビルド

編集元は**`src/index.template.html`**です。生成済みHTMLを直接編集しません。[APP_SPEC.md](APP_SPEC.md)が製品仕様、[開発計画](docs/superpowers/plans/2026-10-05-time-study-desk.md)が後続段階の定義です。既存テンプレートのビルド・共通部品の契約を維持しています。

Windowsでは`build-standalone.bat`を実行できます。全体確認は次の順です。

```powershell
powershell.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -File .\scripts\check-powershell-syntax.ps1
powershell.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -File .\scripts\check-repository.ps1
```

PowerShell 7では次のコマンドを使います。

```powershell
pwsh -NoProfile -File ./scripts/check-powershell-syntax.ps1
pwsh -NoProfile -File ./scripts/check-repository.ps1
```

出力は`dist/index.html`、`dist/index.self-extract.html`、通常版とバイト一致するルートの`time-study-desk.html`、依存・サイズのマニフェストです。ソース変更だけでは生成物は更新されないため、チェックアウト後はビルドしてから使ってください。

開発用テスト（CIはNode 22）は以下です。利用者のアプリ実行にnpmは不要です。

```text
npm ci
npx playwright install chromium
npm run test:unit
npm run test:e2e -- --project=chromium
```

単体テストは実ソースの`TSD:CORE`ブロックを抽出します。テスト用の別実装ではありません。ブラウザ試験は生成HTMLを対象とし、試験動画はアプリへ埋め込みません。Actions成果物には試験対象ソース、HTML二種とルートコピー、実行環境、ブラウザ試験報告、スクリーンショットを含めます。

## 保存形式・開発状態

[保存スキーマ1](docs/SAVE_FORMAT.md)はアプリ版と独立し、v1.0.0まで互換性を維持する方針です。v0.2.0で出力した互換性確認用の`.tsd.json`を`tests/fixtures/`に保持します。検証では未知フィールドや不正参照を黙って読み捨てません。v0.7.0もschema 1を読み込み、v0.2.0のfixtureを互換性回帰として維持します。元動画は分析JSONとは別に、候補照合と本人確認を経て再接続します。統計・根拠区間・CSVは保存データから都度導出し、JSONへ派生値を重複保存しません。

この作業ではリリース公開・PRのマージ・Browser Kitty本体への追加を行いません。PRはユーザー本人がマージします。
